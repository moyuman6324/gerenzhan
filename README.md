# Yang Studio · 个人作品集

React + Vite 单页个人作品集，包含角色主视觉、个人档案 Bento 面板、兴趣世界网格和整屏联系页。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可预览。生产构建使用 `npm run build`。

## 首次个性化

当前页面里的「丹阳 / DAN YANG」、河南、邮箱地址、兴趣和档案数据中，邮箱及兴趣档案仍是展示示例。修改 `src/main.jsx` 中对应文案即可替换。首页动态背景位于 `public/images/yang-hero.gif`，个人头像位于 `public/images/danyang-avatar.jpg`。
